# Bike Sales Dashboard

A small Excel-based data analysis project I worked on during my Diploma in Computer Science Engineering.

I built this project to explore bike sales data and understand how different customer and sales factors affect overall sales performance.

## About the Project

The project uses Microsoft Excel to clean, organize, analyze, and visualize bike sales data.

The dashboard helps explore:

- Sales performance
- Customer demographics
- Product preferences
- Regional sales
- Income and purchasing patterns
- Customer buying behavior

## Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Cleaning
- Charts & Dashboard

## What I Learned

Working on this project gave me practical experience with handling raw data, creating summaries using Pivot Tables, finding patterns in data, and presenting the results through an interactive dashboard.

It was one of my early projects that helped me become interested in **Data Analysis**.
